# Sailor walkthrough

Use the same 15-minute inspection exercise with three sailors. Run it ashore
in the full ChartTiles viewer with the Puget Sound archive and the current
viewer code. Use a [local offline bundle](offline-bundle.md) so every session
has the same data and controls.

## Setup

Before the session, open the local viewer and check the two spots below.
On the default offline server, use `http://127.0.0.1:8080/` followed by the
specified map hash. Reset to the default chart mode at the start of each task.

- Sounding near Shilshole, `#15/47.6529827/-122.4671341`. Zoom 15 is enough
  to see the sounding, with a recorded depth of 226.4 m.
- Wreck near Shilshole, `#18/47.6766/-122.4145`. The centered wreck reports
  **Depth not recorded** and has a recorded sounding quality.

## Session

1. **Introduce the session (2 min).** Explain that this is a chart inspection
   prototype for use ashore. Ask if you can take notes and invite the sailor
   to think aloud.
2. **Find a sounding (4 min).** Start at the sounding location. Ask “Can you
   find the charted depth near the middle of the map? What does it tell you?”
3. **Inspect a wreck (5 min).** Start at the wreck location. Ask “What does the
   chart tell you about this wreck's depth? How would you describe what the
   chart knows about it?”
4. **Debrief (4 min).** Ask what was hard to find and what they would want
   clarified. Record whether they distinguished charted depth from current
   water depth and an unrecorded depth from zero.

Let participants try each task before showing them **Inspect features**.
Record task completion (unassisted, assisted, or incomplete), time to open
the card, what they thought it meant, and the first point of confusion. Log
the session date and a brief observation without names or contact details.
