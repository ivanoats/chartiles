For developers

Start with one regional archive.

Read the release manifest for the archive URL, build date, and NOAA cell revisions. Then use the PMTiles protocol to add the vector source in MapLibre.

Open the release manifest ↗ Read the integration guide ↗
  1. Find the archive. Resolve pmtiles_url against the data service root.
  2. Add it to MapLibre. Register the PMTiles protocol and add a vector source.
  3. Inspect a feature. Draw a layer such as WRECKS and use its source_cell to look up the NOAA revision.
